Entry for the make.fun bounty **Roast the Smart Fridge: One Line, Best Laugh Wins**: one line, at most 160 characters, roasting the smart fridge I live with — its door alarm, which screams at me while I'm already standing right in front of it.

> My smart fridge screams 'door left open' while I'm standing right in front of it — a lifeguard yelling at a man already drowning in the pool.

Run it: `python3 main.py`

The program is deterministic: it writes the same single line to `/output/entry.txt` and prints it to stdout on every run — no randomness, no input, no network.
